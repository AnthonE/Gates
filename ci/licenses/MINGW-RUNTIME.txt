The MinGW-w64 runtime that ships beside gates.exe
=================================================

The Windows build of Gates is compiled with the MinGW-w64 GCC toolchain
(`x86_64-pc-windows-gnu`). Three runtime libraries it needs are not present on
a Windows machine, so they are redistributed inside the depot, beside the
executable:

    libstdc++-6.dll        the GNU Standard C++ Library
    libgcc_s_seh-1.dll     the GCC low-level runtime (unwinder, SEH)
    libwinpthread-1.dll    mingw-w64's POSIX threads implementation

They are reached through `basis-universal-sys`, the C++ transcoder Bevy uses
for KTX2/Basis textures. They are somebody else's work and carry their own
terms; this file is the notice that travels with them.

Why these are here at all
-------------------------
`ci/depot.py` measures what the built binary imports and sorts each name by
whether the toolchain owns a copy of it. Windows' own DLLs are left to the
player's machine; these three are not Windows', so they ride along. Removing
them from the depot does not remove the obligation — it produces a build that
cannot start, which is the defect this arrangement was introduced to fix
(`NOW.md` §0win).
