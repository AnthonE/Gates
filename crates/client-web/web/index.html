Gates — web client

Gates in a tab. It joins a shard over WebTransport with your own wallet, then hands the live session to the renderer — the same Rust client the desktop build runs, compiled to WebAssembly. Connect a wallet if the shard requires one; a shard that takes guests will let you in without.

not connected — a shard that takes guests will still let you in
idle.
A browser cannot skip certificate validation, so there is no loopback carve-out here — that is the one place this client is stricter than the desktop one. The signature your wallet shows you is built in Rust by the same function the shard uses to check it; this page never composes it. Models do not draw yet: their textures are KTX2/UASTC and the transcoder is C++, which does not build for this target.
